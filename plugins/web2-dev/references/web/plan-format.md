# Plan Format Contract

plan.md 是 exec skill 唯一依赖的产物。只包含任务分解清单，不包含设计内容。

## 格式规范

```markdown
# Plan — 任务清单

## 元信息
- 模式: {new|feat|refactor}
- 技术栈: {语言/框架}
- 模块数: {N}

## 任务列表

| # | 模块 | 简要说明 | 涉及路径 |
|---|------|---------|---------|
| 1 | {模块名} | {一句话描述} | {源码路径}, {测试路径} |

## 前端

开发方式: {从 layouts/ 设计稿编码 | 无前端}
前端入口: {路径}
```

## Exec 解析规则

exec 读取 plan.md 时：

1. 从 `## 任务列表` 表格中提取任务清单，按行号顺序串行执行
2. 每个任务的模块名用于在 design.md 中查找对应章节
3. `## 前端` 章节存在且 `开发方式` 不是 "无前端" → 执行前端阶段
4. 不解析表格之外的文本

## 约束

- 表格中不包含设计细节——exec 去 design.md 按模块名查找
- 任务数量 = design.md 中的模块数
- 任务顺序 = 依赖关系排序（被依赖的在前）
- 前端不拆分，始终作为一个整体
